# 仓库说明

收录自用 AI 扩展。扩展清单见 [extensions.md](extensions.md)。

## 作用域规则

- **`通用`**：安装至所有目标 AI 客户端。
- **`<特定客户端名称>`**（如 `claude code`）：仅安装至对应名称的 AI 客户端。

## 自动安装步骤

1. **远端读取本仓库**：**严禁克隆本仓库**，直接通过 Raw 链接远端获取本仓库相关内容。
2. **列出清单**：解析 `extensions.md`，结合作用域规则，输出当前客户端可安装的扩展列表。
3. **确认安装范围**：询问用户需要安装列表中的哪些扩展（支持全选或指定部分），**等待用户回复确认后再继续**。
4. **读取与安装**：按用户确认的名单，逐个读取扩展链接中的安装说明并执行（修改本地配置文件时仅作增量合并，保留原有配置）：
   - **GitHub 仓库**：直接获取 `README.md` 的 Raw 纯文本，默认不克隆完整仓库。
   - **官方网站/文档页**（非 GitHub 链接）：直接抓取页面正文内容（或检索页面内的 Docs / Quickstart 入口），提取其中的安装与配置指令。
5. **单步确认与验证**：每安装完一个扩展，必须暂停并等待用户确认；若原文档包含验证步骤或需用户输入的测试指令，同步输出给用户。
