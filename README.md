# 仓库说明

本仓库用于收录和管理自用的 AI 扩展（MCP、Skills、Plugins）。

## 扩展名单

详见 [extensions.md](extensions.md)。

**安装范围规则**：

- **`通用` 分类**：为当前环境中的所有目标 AI 客户端安装。
- **特定客户端分类**（如 `claude code`）：仅安装至对应名称的 AI 客户端中。

## 安装或更新流程

1. **确认待装列表**：读取 `extensions.md`，结合当前目标 AI 客户端，输出本次需安装或更新的扩展清单。
2. **远端解析并安装**：
   - 直接获取各扩展官方仓库的 `README.md` 纯文本（优先通过 `raw.githubusercontent.com/<owner>/<repo>/HEAD/README.md` 读取，默认不克隆完整仓库）。
   - 解析文档中的官方安装步骤，以增量合并方式更新本地配置或执行安装命令（严禁覆盖已有配置）。
   - 若安装过程需要配置 API Key 等环境变量，先向用户索取或填入占位符并提示。
3. **逐项验收确认**：
   - **每完成一个扩展**的安装，立即暂停并交由用户确认，确认无误后再继续下一个。
   - 若原文档提供了验证方法或需要用户手动执行的检查指令，需在确认环节一并提供给用户。
